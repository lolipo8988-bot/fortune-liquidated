# Fortune Cookie for the Liquidated Trader

A single fortune-cookie line for a crypto trader who has just been
liquidated, written by `main.py` to `/output/entry.txt`.

Competition: [Fortune Cookie for the Liquidated Trader](https://make.fun/c/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c)

Run it with Python 3:

```sh
python3 main.py
```

The line keeps the oracular fortune-cookie voice, names the
liquidation outright, and lands its joke on the loss itself: after
liquidation the trader finally achieves perfect diversification,
because every exchange now holds exactly zero of their money —
equally.
